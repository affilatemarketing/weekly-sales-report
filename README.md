# Weekly Sales Report

Turn a sales CSV into weekly transaction counts and revenue totals. Open index.html in a browser and click Generate report to try the sample.

Export a sheet as CSV with the header date,product,amount. Use ISO dates and nonnegative USD amounts with up to two decimals. Paste the CSV into the tool. Each row is one sale and weeks start Monday. The sample should show two sales totaling $37.50 and one sale totaling $30.00.

The tool runs locally in the browser and sends no sales data to a server.

## Custom reporting

I can adapt this tool to your spreadsheet format or add summaries by product, location, or sales channel. Open a GitHub issue with a description of your reporting needs and a few fictional sample rows.
